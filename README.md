# Soccer-Stats-Percentile-Pizza-Charts
This project uses R (worldfootballR, ggplot2, dplyr) to compare Diogo Dalot, Jeremie Frimpong, and Geovany Quenda in key attributes for a wing-back role in Rúben Amorim’s 3-4-3 system. It features radar charts and stat slicers for player evaluation.
